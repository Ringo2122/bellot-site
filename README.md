# БелЛот — прототип агрегатора торгов

Сайт: https://ringo2122.github.io/bellot-site/

Каталог торгов по имуществу должников с трёх площадок: e-auction.by (БелЮрОбеспечение),
ipmtorgi.by (ИПМ-Торги), beltorgi.by (Белреализация). Разделы: недвижимость, легковые авто,
грузовые и автобусы, спецтехника, оборудование (от 3 000 BYN).

## Как обновляется

GitHub Actions (`.github/workflows/update.yml`) в **11:00 и 18:00 по Минску**:

1. `app/update.rb` — обходит площадки: новые лоты добавляет, у известных обновляет цену и срок,
   закрытые отправляет в архив (срок заявок истёк или лот снят с площадки). Архив хранится 180 дней.
2. `app/market.rb`, `app/market_realty.rb` — рыночный ориентир по Kufar для новых лотов.
3. Память коммитится в `data/`, `app/build.rb` собирает сайт в `_site/` и выкладывает на Pages.

Запустить вручную: Actions → «Обновление сайта» → Run workflow.
Правка кода в `app/` пересобирает сайт без обхода площадок.

## Память

| Путь | Что |
|---|---|
| `data/lots.json` | короткие записи всех лотов, строка на лот; `status`: `active` / `archive` |
| `data/det/<key>.json` | подробности лота |
| `data/ph/<key>.jpg` | фото, 400 px |

`data/` пишет только робот. Руками не править — следующий прогон перезапишет.

## Локально

```bash
ruby app/update.rb && ruby app/build.rb    # сайт в _site/
```

Нужны ruby и curl; для фото — `sips` (macOS) или ImageMagick.
